# Luxury Hotel Website

This is a simple HTML website for a fictional luxury hotel.

## Files

- `index.html`: Main HTML structure
- `style.css`: CSS styles for the website
- `script.js`: JavaScript for interactivity (form handling, smooth scrolling)

## Usage

Open `index.html` in your web browser to view the website.

## Features

- Responsive design
- Sections: Home, About, Rooms, Contact
- Contact form with basic JavaScript handling
- Smooth scrolling navigation

## Troubleshooting

- Ensure your browser supports HTML5 and JavaScript.
- If styles don't load, check if the file is opened directly in the browser and that `style.css` is in the same directory.
- If JavaScript doesn't work, ensure `script.js` is present and JavaScript is enabled in your browser.
